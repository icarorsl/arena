# FILE Group — C# Client

## Prerequisites

- .NET 8.0 SDK
- Client certificate + key + CA cert (generated by `dbctl tls init`)
- API key (from cluster config)

## Run Demos

```bash
dotnet run --project DemoLocal           # Docker/local (no TLS)
dotnet run --project Demo                # Production (mTLS + certs)
```

### Verify replication across a cluster

With the 3-node Docker cluster running (`cd ../../filegroup && make up`):

```bash
# Upload to node1 and read the file back from node2 (a different node)
dotnet run --project DemoLocal -- http://localhost:8443 http://localhost:8444
```

A result of `match: True` means both Raft metadata and chunk replication are
working. `DemoLocal` creates the default table if it is missing, and retries the
cross-node read briefly while the follower catches up with the Raft commit.

## Web Dashboard

A browser dashboard for exploring and managing files, versions and tables.

```bash
dotnet run --project WebDashboard --urls http://localhost:5001
# Open http://localhost:5001
```

It is **cluster-aware**: `Engine:Nodes` in `appsettings.json` lists the engine
URLs, and the dashboard fails over to the next node when the active one is
unreachable. Requirements: the engines run (Docker or native); with the default
config it starts on `localhost:8443` and can fall back to `8444`/`8445`.

Pages of note:
- **Status** — every node with its Raft role (leader/follower), leader id and
  commit/apply index.
- **Replication** — uploads a small probe file to the active node and reads it
  back from *every* node, reporting MATCH/FAIL per node. This is the UI form of
  `make verify` and only passes when Raft metadata and chunk replication work.
- Tables / Files / Upload / File / Play / Segments for everyday use.

```csharp
using FileGroup;

using var client = new FileGroupClient(
    engineAddress: "https://localhost:8443",
    clientCertPath: "certs/client.crt",
    clientKeyPath:  "certs/client.key",
    caCertPath:     "certs/ca.crt",
    apiKey:         "your-api-key-here");

// Upload a file
var session = await client.OpenSessionAsync(
    groupId: 1, tableId: 5, totalSize: 1048576);
await client.WriteChunkAsync(session.SessionId, 0, chunkData);
await client.CompleteSessionAsync(session.SessionId);

// Read it back
var data = await client.ReadFileAsync(logicalFileId: session.LogicalFileId);

// List files
var files = await client.ListFilesAsync(groupId: 1, tableId: 5);

// Delete
await client.DeleteFileAsync(session.LogicalFileId);
```

## Authentication

Two layers:
1. **mTLS** — configured via `clientCertPath`/`clientKeyPath`/`caCertPath`
2. **API key** — passed as `x-api-key` gRPC metadata header on every request
